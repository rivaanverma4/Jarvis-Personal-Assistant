# JARVIS (Ricky) — Desktop AI Companion

A desktop AI companion built with Electron, powered by the Gemini Live API
("Just A Rather Very Intelligent System" — a British-butler-style voice assistant).
It speaks when you say "JARVIS", and can search the web, generate and edit
images, draw diagrams, save notes, and drive macOS apps in Computer Control Mode.

Built by "Ricky" (the package name is `ricky`); JARVIS is its main name.

## Requirements

- macOS (the automation tools use `open` and AppleScript/osascript)
- Node.js (needed for `npm` and Electron)

## Setup

```bash
cd /Users/rivaan/Documents/Jarvis
npm install
npm start
```

`npm start` runs `electron .` — the app window appears after a moment and the
face says "Online — say \"JARVIS\"" once connected. The `npm run postinstall`
hook (run automatically by `npm install`) copies `mermaid.min.js` into the
folder so the diagram renderer works.

> **Add your own API keys first.** You need to add your own Exa and Gemini
> Live API keys — they belong in `config.js` (see the `config.js` entry in the
> file list, or fill in the key fields at the top of the file).
>
> **Keep `config.js` private.** It holds those API keys. Don't commit it to
> any repository or share it; nothing here ignores it by default (see
> `.gitignore`).

## Using it

- **Voice** — Say "JARVIS" (or "Ricky") to start talking. Watch the status
  label for "Online — say \"JARVIS\"", "Listening", "Mic Off", or "Editing…".
- **Artifacts panel (right side)** — Search results from Exa, generated
  images (16 slots, use slot numbers to reference them), Mermaid diagrams,
  and your saved local notes appear here. Say "show me the menu" for the
  capabilities panel.
- **Quick voice commands** — "Generate an image of a fox", "Pull up photo 13",
  or while an image is open in the lightbox: "give him blue sunglasses".
- **Computer Control Mode** — Toggle the button on the left. JARVIS collapses
  to a floating 76×76 orb at the bottom of your screen; say things like "open
  Safari" or "type <text>" and it types for you. Toggle it off to restore the
  full window.
- **Mic button** — Mute/unmute the microphone ("Mic Off" status).

## Files

| File | What it does |
| --- | --- |
| `main.js` | Electron main process: window and orb mode, IPC handlers, macOS automation (launch apps, type text via clipboard + Cmd+V, press keys, open URLs), Exa web search, Imagen image generation/editing, local notes storage |
| `renderer.js` | Renderer: Gemini Live WebSocket client, tool dispatch, artifacts rendering, lightbox, Mermaid rendering, animated face |
| `index.html`, `styles.css` | UI markup and styling |
| `config.js` | API keys — `GEMINI_API_KEY`, `EXA_API_KEY` (see note above) |
| `preload.js` | Exposes the `window.ricky` IPC bridge to the renderer |
| `pcm-capture-processor.js` | AudioWorklet that captures the microphone as PCM for Gemini Live |
| `mermaid.min.js` | Generated by `npm run postinstall` |
| `.gitignore` | Ignores `node_modules/`, `dist/`, `*.log`, `.DS_Store` |

Notes and generated assets are stored in Electron's `userData` directory
(typically `~/Library/Application Support/ricky` on macOS): `local-notes.json`
and `assets/manifest.json` + `asset_<timestamp>.png`.

## Tools JARVIS uses

`save_local_note`, `exa_web_search`, `render_mermaid_diagram`,
`generate_image`, `edit_image`, `view_image`, `show_capabilities`, and in
Computer Control Mode `launch_app`, `type_text`, `press_key`, `open_url`.
